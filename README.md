# TokenBridgeMax

TokenBridgeMax enables high-performance, bi-directional data replication across multiple protocols, establishing a scalable gateway for inter-module communication.

TokenBridgeMax is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/TokenBridgeMax.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
